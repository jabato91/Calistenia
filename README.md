Calisapp
¿Qué es?

Una aplicación móvil para gestionar rutinas de ejercicios de calistenia y hacer seguimiento del progreso del usuario.
Tecnologías utilizadas

.NET MAUI — framework de Microsoft para crear apps multiplataforma (Android, iOS, Windows) con una sola base de código en C#.
SQLite — base de datos local ligera, donde se guardan rutinas, ejercicios y el historial de progreso del usuario.

Funcionalidad principal

Creación y gestión de rutinas de ejercicios de calistenia.
Seguimiento del progreso del usuario a lo largo del tiempo (series, repeticiones, evolución).

¿Por qué este enfoque?

.NET MAUI permite desarrollar para varias plataformas a la vez, y SQLite es ideal para una app de este tipo porque no necesita conexión a internet ni un servidor: todos los datos del usuario se guardan directamente en el dispositivo.
